# proxmox-opnsense-homelab
A hands-on home network lab utilizing Proxmox VE as a bare-metal virtualization platform to host OPNsense as a virtualized router and firewall. The project focuses on building, configuring, securing, and troubleshooting a dedicated network while exploring routing, switching, VLANs, DHCP, DNS, NAT, firewall policies, network segmentation, security.
